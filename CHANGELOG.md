# Changelog

All notable changes to this project will be documented in this file.

## [0.1.2] - 2026-08-16

### Added

- Vault-wide grounded chat with local hybrid retrieval.
- Real model discovery for OpenAI-compatible services.
- Local task sessions, Vault audit tools and optional Vault-scoped filesystem access.
- Confirmed change proposals for create, modify, move and recycle-bin deletion.
- Clickable internal links, evidence entries and compact Markdown rendering.

### Security

- Credentials use Obsidian SecretStorage.
- Cloud services receive retrieved context rather than the complete Vault.
